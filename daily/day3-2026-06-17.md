## 五、面试考点沉淀

### 考点 7：createStaticStyles 零运行时 CSS-in-JS

antd-style 的 `createStaticStyles` 在**编译时**就将样式提取为静态 CSS，运行时不需要注入 `<style>` 标签。对比传统 CSS-in-JS（如 styled-components、Emotion）：

| | createStaticStyles | Emotion / styled-components |
|---|---|---|
| 提取方式 | 编译时 | 运行时 |
| CSS 注入 | 无（纯 CSS 文件） | `<style>` 标签动态注入 |
| SSR 兼容 | 天然兼容 | 需要额外配置 |
| 动态值 | `cssVar.*` token | `${props => ...}` 插值 |
| 性能 | 零运行时开销 | 每次渲染计算样式 |

### 考点 8：Feature 组件设计模式

LobeHub 的 `src/features/` 目录规范：
- 每个 feature 是一个独立文件夹
- 内部可以有 `index.tsx`、`hooks/`、`components/`、`style.ts` 等
- feature 之间通过 imports 组合，不允许循环依赖
- 业务逻辑 + UI 都放在 feature 内；路由文件只做薄层 import
