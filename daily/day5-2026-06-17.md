## 四、面试考点

### RAG 集成模式
用户面经 → LobeHub Files API → chunk+embed → pgvector → searchKnowledgeBase → Agent 上下文

### Builtin Tool 插件机制
- `plugins: [KnowledgeBaseIdentifier, ...]` 声明工具能力
- 模型通过 Function Calling 自主决定调用
- System Prompt 中 MUST 指令引导调用频率
